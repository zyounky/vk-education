# VK Education — практическое задание 4, часть 2

Каталог приложений, готовая карточка из практики и витрина с переходами на Jetpack Compose Navigation. Основа — часть 1 в ветке `homework/04-compose-app-list`.

## Что реализовано

- Главный экран: тулбар и `LazyColumn` из части 1 с восемью статичными приложениями.
- Нажатие на любое приложение открывает готовую карточку «Гильдия Героев» из репозитория практики.
- Внизу карточки добавлен отдельный `AppShowcase` с заголовком «Витрина» и `HorizontalPager`.
- В витрине ровно три страницы, по три приложения на каждой. Все девять приложений заданы в `ShowcaseData.kt`.
- Витрина использует тот же `AppItem`, что и основной список. Любой элемент кликабелен и возвращает к существующему списку, не создавая его копию в истории.
- Переходы выполняет `NavHost` с двумя `composable`, `rememberNavController`, `navigate` и `popBackStack`.
- В карточке работают «Назад», раскрытие описания и системное меню «Поделиться». Установка приложения и открытие разработчика остаются демонстрационными действиями, как в образце практики.
- Изображения карточки сохранены в ресурсах: для просмотра сети и разрешения INTERNET не требуется.

## Источник готовой карточки

Использована карточка из [maltsevmicyou/VkEducation](https://github.com/maltsevmicyou/VkEducation/tree/b4c673b), commit `b4c673b`.

Перенесены компоненты `AppDetailsHeader`, `AppDescription`, `Developer`, `InstallButton`, `Toolbar`, `ScreenshotsList` и структура `AppDetailsContent`. Сохранены их расположение, размеры и визуальные блоки. Адаптация состоит в замене package/импортов, использовании локальных ресурсов вместо загрузки через Coil, упрощении источника данных до статичного примера и добавлении витрины. Сервер, Hilt и Room из более поздних изменений репозитория для этой UI-практики не нужны.

Все пункты основного списка намеренно открывают одну готовую карточку из практики, как указано в задании. Изображения принадлежат их правообладателям и используются в учебном примере; исходные адреса из репозитория перечислены в `ASSET_SOURCES.txt`.

## Структура

Kotlin-файлы находятся в `app/src/main/java/com/example/vkeducation/`.

- `ui/AppNavigation.kt` — граф навигации.
- `ui/AppListScreen.kt` — основной каталог из части 1.
- `ui/appdetails/` — готовая карточка и её компоненты.
- `ui/components/AppItem.kt` — общий элемент приложения.
- `ui/components/AppShowcase.kt` — витрина.
- `data/AppsData.kt`, `data/ShowcaseData.kt`, `data/AppDetailsData.kt` — статичные данные.
- `model/` — модели элементов списка и карточки.

## Сборка и проверка

Откройте проект в Android Studio с поддержкой AGP 9.4.1. Требуется Android SDK Platform 37; минимальная версия устройства — API 26. Путь к SDK задаётся через Android Studio, `local.properties` или `ANDROID_HOME`.

Проект использует Gradle Wrapper 9.6.0. Для запуска wrapper подходит JDK 21; версия JVM для Gradle daemon закреплена исходным `gradle/gradle-daemon-jvm.properties` как Java 25.

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest --console=plain
.\gradlew.bat :app:connectedDebugAndroidTest --console=plain
```

Вторая команда требует запущенного Android-эмулятора или подключённого устройства. На macOS/Linux используется `./gradlew`.

`ShowcaseNavigationTest` проверяет переход в готовую карточку, возврат кнопкой «Назад», перелистывание всех трёх страниц, отсутствие четвёртой страницы и возврат из каждой страницы витрины в основной список.

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Отчёт Lint: `app/build/reports/lint-results-debug.html`.

## Ручная проверка

1. Нажмите любую карточку в основном списке.
2. Прокрутите экран до заголовка «Витрина».
3. Проверьте три страницы горизонтальным свайпом; индикатор меняется от «1 из 3» до «3 из 3», на каждой странице по три приложения.
4. Нажмите любое приложение в витрине: откроется исходный список.
5. Снова откройте карточку и вернитесь кнопкой в тулбаре или системной кнопкой «Назад».
