# VK Education — практическое задание 4, часть 1

Экран каталога приложений на Kotlin и Jetpack Compose.

## Выполнено

- Вверху расположен тулбар с акцентным фоном, названием экрана и иконкой текущего приложения слева.
- Под тулбаром — вертикальный прокручиваемый список `LazyColumn`.
- Каждая карточка содержит собственную иконку, название, краткое описание и категорию.
- Восемь приложений заданы в коде; сетевые запросы и разрешение на интернет не нужны.
- Есть светлая и тёмная темы. Список учитывает системные отступы, переносит текст при увеличении шрифта и ограничивает ширину на планшете.
- Карточки объединяют текст в один элемент доступности; декоративные иконки не повторяют название для TalkBack.

Переходы по карточкам не входят в эту часть задания. Для добавления взаимодействия `AppItem` принимает обычный `Modifier`.

## Структура

- `model/AppInfo.kt` — модель приложения.
- `data/AppsData.kt` — статичные данные.
- `ui/AppListScreen.kt` — тулбар, список и Compose Preview для телефона, планшета, тёмной темы и крупного шрифта.
- `ui/components/AppItem.kt` — карточка приложения.
- `ui/theme/` — тема и типографика.
- `res/drawable/ic_app_*.xml` — локальные векторные иконки.

Все Kotlin-файлы находятся в `app/src/main/java/com/example/vkeducation/`.

## Сборка и запуск

1. Откройте проект в Android Studio с поддержкой Android Gradle Plugin 9.4.1.
2. Установите Android SDK Platform 37 и укажите путь к SDK через Android Studio, `local.properties` или `ANDROID_HOME`.
3. Выполните синхронизацию Gradle и запустите конфигурацию `app` на эмуляторе или устройстве с Android 8.0 / API 26 и новее.

Проект использует Gradle Wrapper 9.6.0. Для запуска wrapper подходит JDK 21; версия JVM для Gradle daemon закреплена в исходном `gradle/gradle-daemon-jvm.properties` как Java 25 и provisioned через указанные там URL при необходимости.

Проверка в PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug --console=plain
```

На macOS/Linux используйте `./gradlew`. Debug APK создаётся по пути `app/build/outputs/apk/debug/app-debug.apk`, отчёт Android Lint — `app/build/reports/lint-results-debug.html`.

## Проверка интерфейса

1. Убедитесь, что на старте видны тулбар и первые приложения.
2. Прокрутите до последней карточки «Погода».
3. Проверьте тёмную тему и увеличенный системный шрифт: текст не должен перекрываться, список должен прокручиваться.
4. Поверните устройство: список остаётся под тулбаром и помещается по ширине.
