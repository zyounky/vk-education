# Практическое задание 3 — Intent

Курс VK Education «Основы Android-разработки», задание «Основы и структура android приложения» (№ 14760).

## Что сделано

- `MainActivity`: обычное поле **EditText** и три кнопки из задания.
- «Открыть вторую Activity»: явный `Intent`, передача исходной строки в `EXTRA_TEXT`, отображение в `SecondActivity`.
- «Позвонить другу»: неявный `ACTION_DIAL` с URI `tel:`. Приложение открывает набор номера; разрешение `CALL_PHONE` не требуется.
- «Поделиться текстом»: `ACTION_SEND`, тип `text/plain`, текст в `Intent.EXTRA_TEXT`, системное меню через `Intent.createChooser`.
- Пустой текст и неверный номер показывают ошибку у поля ввода. Номер допускает 3–15 цифр, начальный `+`, пробелы, скобки и дефисы; форматирование удаляется перед передачей в приложение телефона.
- Если приложение набора номера отсутствует, выводится сообщение вместо аварийного завершения.
- Исходный текст сохраняется при возврате и пересоздании Activity. Экраны учитывают системные панели и клавиатуру, содержимое можно прокрутить.
- `SecondActivity` зарегистрирована в манифесте и не экспортируется.

## Запуск

Откройте проект в Android Studio, дождитесь синхронизации и запустите конфигурацию `app` на устройстве Android 8.0 (API 26) или новее.

Проект использует исходные настройки репозитория: JDK 25, Gradle 9.6.0, Android SDK 37. Путь к SDK задаётся локально в `local.properties` и не попадает в Git.

```shell
./gradlew assembleDebug testDebugUnitTest lintDebug
./gradlew connectedDebugAndroidTest
```

В Windows используйте `gradlew.bat`. Для последней команды нужен запущенный эмулятор или подключённый Android.

## Проверка вручную

1. Введите текст, откройте вторую Activity: должен отобразиться тот же текст. Вернитесь назад — введённое содержимое сохранено.
2. Введите `+7 (999) 123-45-67`, нажмите «Позвонить другу»: откроется приложение телефона с номером `+79991234567`.
3. Введите текст, нажмите «Поделиться текстом»: откроется системный выбор приложения для отправки.
4. Попробуйте пустое поле, пробелы и текст вместо номера: появится ошибка, перехода не произойдёт.
5. Поверните устройство на обоих экранах: текст сохранится.

Автоматические проверки покрывают валидацию номера, передаваемые Intent, отображение текста, возврат, ошибки ввода и пересоздание Activity.
